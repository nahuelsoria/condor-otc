# Condor OTC / Condor Capitals — Case Study

> Cross-border payments & exchange platform. Built the financial integrations and the tooling international operations run on.

This repository is a public **case study** of work I led. It contains no proprietary code or confidential data — only an overview of the product, my role, and the engineering approach.

## Overview

Condor OTC is a payments and exchange platform supporting international operations — moving and converting value across currencies and providers, and giving the desk the tooling to run it.

## My role

**CTO / Technical Lead.**

## What I built

- **Financial provider integrations** for payments and exchange.
- **Multi-currency operations** flows for cross-border movement.
- **Internal desk tooling** the operations team uses day to day.

## Engineering approach

- Integration-heavy architecture, with each provider isolated behind a common internal interface.
- Operational tooling designed for speed and correctness under real desk workload.

## Stack

`TypeScript` · `Next.js` · `Node.js` · `PostgreSQL / Firebase` · provider & exchange APIs

## Outcomes

Supports live international operations.
